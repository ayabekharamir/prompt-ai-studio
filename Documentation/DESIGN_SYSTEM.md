# Prompt AI Studio
# Design System


## 1. Design Philosophy


Prompt AI Studio should feel:

- Intelligent
- Modern
- Professional
- Creative
- Trustworthy
- Simple


Design direction:

AI technology + Human creativity


The interface should communicate:

"Your brand has an intelligent creative brain."
