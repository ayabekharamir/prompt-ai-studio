# Prompt AI Studio — Assets

Shared static assets for the Phase 1 development foundation: logos,
icons, and other brand-approved visual files used across the frontend
application and documentation.

## Guidelines
- Only place **final, approved** brand assets here (sourced from the
  existing `Brand/` documentation from Phase 0) — do not generate
  placeholder or fake brand assets.
- Frontend-specific static files that Next.js serves directly (favicons,
  og-images, etc.) should live under `frontend/public/` once assets are
  finalized; this folder is the shared source location before they're
  copied into the app.
- Suggested subfolders as the project grows: `logos/`, `icons/`, `illustrations/`.
