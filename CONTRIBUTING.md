# Contributing to Prompt AI Studio

Thank you for your interest in contributing to Prompt AI Studio (PAS). This document covers Phase 1 contribution guidelines, which currently focus on documentation and product foundation rather than code.

## 1. Current Phase Scope

Phase 1 of this repository is **documentation-only** (Brand, Product, Strategy, UX, Business, AI foundations). Code contributions will open once Phase 1 engineering begins; this document will be updated accordingly.

## 2. How to Contribute (Phase 1)

1. **Fork** the repository.
2. **Create a branch** for your change: `git checkout -b docs/short-description`.
3. **Make your changes** to the relevant Markdown file(s).
4. **Follow the naming and terminology conventions** defined in `Documentation/NAMING.md` and `Documentation/GLOSSARY.md`.
5. **Keep bilingual consistency** — if you edit an English section that has a Persian counterpart, update both.
6. **Submit a Pull Request** with a clear description of what changed and why.

## 3. Documentation Standards

- Do not introduce fabricated statistics, customer names, or unverified claims.
- Use placeholders (`[TBD]`) for any figures or details not yet finalized.
- Keep tone aligned with `Brand/BRAND_VOICE.md`.
- Maintain the existing folder structure; new documents should be placed in the most relevant category folder.

## 4. Commit Message Convention

We recommend a simple, readable format:

```
docs(brand): update brand voice guidelines
docs(product): clarify Phase 1 feature scope
docs(strategy): refine market positioning
```

## 5. Code of Conduct

All contributors are expected to follow `CODE_OF_CONDUCT.md`.

## 6. Questions

For questions about contribution scope or direction, please open an issue describing your proposed change before submitting a large Pull Request.
