# Prompt AI Studio — Prompts

This folder documents the **structure and taxonomy of prompts** produced
and stored by Prompt AI Studio. It is documentation only (no source code) —
the actual `Prompt` data model lives in `backend/app/models/prompt.py`
and the table lives in `database/schema.sql`.

## Files
- `PROMPT_STRUCTURE.md` — the anatomy of a single prompt record and how
  it relates to a brand and a template.
- `PROMPT_CATEGORIES.md` — the category taxonomy used to organize
  prompt templates and prompts across the platform.
