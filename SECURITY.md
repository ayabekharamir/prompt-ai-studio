# Security Policy — Prompt AI Studio

## 1. Current Phase Notice

Phase 1 of this repository is documentation and product-foundation only — **no application code, infrastructure, or live service exists yet.** This policy establishes the process to be used once implementation begins, and for handling any security concerns related to this documentation repository itself (e.g., leaked credentials accidentally committed).

## 2. Reporting a Vulnerability

If you discover a security concern related to this repository (e.g., sensitive information accidentally included in documentation), please report it privately rather than opening a public issue:

- **Email:** `security@promptaistudio.com` *(placeholder)*
- **Response Time:** We aim to acknowledge reports within `[TBD]` business days.

Please do not disclose security issues publicly until they have been reviewed and addressed.

Once engineering begins (Next.js frontend, FastAPI backend, PostgreSQL database), this document will be expanded to include:
