# Visual Identity — Prompt AI Studio

## 1. Purpose

This document defines the foundational visual direction for Prompt AI Studio. It is a Phase 1 guideline intended to be expanded by a design team into a full visual system (logo files, color tokens, UI kit) in later phases.

> Note: No final logo or color assets are included in Phase 1. This document defines direction and placeholders only.

## 2. Visual Concept

The visual identity should reflect the brand's core metaphor: **a structured, intelligent "brain"** for brand content — combining the precision of a professional SaaS tool with the approachability of a creative studio.

## 4. Typography Direction (Placeholder)

| Use | Direction |
|---|---|
| Latin / English UI | Modern, geometric sans-serif (e.g., Inter, Söhne-style) |
| Persian UI | Clean, professional Persian sans-serif (e.g., Vazirmatn or similar) |
| Headings | Slightly bolder weight for hierarchy and confidence |
| Body Text | Regular weight, optimized for long-form documentation and dashboards |

## 5. Logo Direction (Placeholder)

- Wordmark-based logo: "Prompt AI Studio" in a clean, modern typeface.
- Optional abstract mark suggesting a "node / brain / prompt bracket" concept (e.g., stylized `{ }` or neural-node motif).
- Must remain legible in both English and Persian brand name variants.
- Final logo files (SVG, PNG, favicon set) are out of scope for Phase 1 documentation and will be produced by a design team.

## 6. UI Visual Principles

1. **Whitespace-first** — dashboards should feel organized, not dense.
2. **Card-based structure** — prompts, brand brain fields, and templates presented as clear, modular cards.
3. **Minimal color noise** — accent color reserved for AI-related or interactive elements only.
4. **Bilingual layout readiness** — UI structure must support both LTR (English) and RTL (Persian) layouts.
