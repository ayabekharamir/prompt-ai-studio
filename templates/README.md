# Prompt AI Studio — Templates

Documentation for the **Prompt Template** system: reusable, placeholder-based
prompt skeletons that users select and fill in to build a final prompt.
The data model lives in `backend/app/models/prompt_template.py` and the
table lives in `database/schema.sql` (`prompt_templates`).

## Files
- `TEMPLATE_STRUCTURE.md` — anatomy of a template and placeholder syntax.
